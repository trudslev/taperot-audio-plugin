HOW IT IS USED HERE
-------------------
This font is NOT embedded in any shipped binary and is NOT required to build
TapeRot. It was used once, offline, to render the "TAPEROT" Dymo nameplate to
design/dymo/taperot-dymo@3x.png, which is what the plugin actually ships.

It is kept in the repository solely so that artwork can be regenerated if the
nameplate design ever changes. See Source/GUI/DymoLabel.h for the rendering
history and the reason the live text was baked.

Note that the author's terms address *use* rather than redistribution of the
font file. If that distinction ever matters — for example if this project stops
being free and non-commercial — revisit it with the author rather than assuming
this notice covers it.
